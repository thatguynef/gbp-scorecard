# Documentation

**GBP Scorecard is built for local home-service businesses** — plumbing, HVAC, roofing, electrical, pest control, garage door, landscaping, restoration, cleaning, and similar trades — and for the marketers and analysts who serve them.

New here? Read [Who it's for](audience.md), then [Why this exists](why-this-exists.md).

This directory also builds into a documentation site: [thatguynef.github.io/gbp-scorecard](https://thatguynef.github.io/gbp-scorecard/), deployed by `.github/workflows/docs.yml`.

## Part of the scorecard family

This is the profile layer of a three-part diagnostic. Each score is independently meaningful, and none rewrites another.

| Scorecard | Question it answers | Live site |
|---|---|---|
| **Local Visibility** | Can prospective customers discover the business across Search, Maps, AI answers, competitors, and external authority? | [Open Local Visibility](https://thatguynef.github.io/local-visibility-scorecard/) |
| **GBP Scorecard** (this repository) | Does the Google Business Profile create trust and enable action? | [Open GBP Scorecard](https://thatguynef.github.io/gbp-scorecard/) |
| **Website Scorecard** | Can the owned website convert that demand? | [Open Website Scorecard](https://thatguynef.github.io/website-scorecard/) |

Read [The Scorecard Family](scorecard-family.md) for the ownership matrix and shared conventions.
